not on this copy

The operator dashboard reads live state from a gateway's API and WebSocket, behind a sign-in. This copy of the site is a set of static files on a file host, with no gateway behind it, so there is no dashboard to open here. Nothing on this page stands in for one.

run it yourself

Start a gateway in simulate mode and the dashboard, the demo and the API all answer on your own machine, at http://127.0.0.1:8080/app by default. Every value it shows is simulated.

the gateway, with a simulated room 
cd rust
cp crates/saans-gateway/saans.example.toml saans.toml
cargo run --release -p saans-gateway -- --config saans.toml --simulate --speed 10
